# EkoTwin – Frontend

KOBİ İkiz Dönüşüm Karar Destek Sistemi'nin kullanıcı arayüzü bu klasörde yer alacaktır.

## Planlanan ekranlar
- Firma kaydı
- 16 soruluk değerlendirme anketi (4 boyut × 4 soru, 1-5 ölçeği)
- Sonuç raporu: genel skor, 4 boyut skoru, olgunluk seviyesi (radar grafik)
- Firmanın geçmiş değerlendirmeleri

## Backend bağlantısı
API, `backend/EkoTwin` projesidir. Geliştirme ortamında:

- API adresi: `http://localhost:5268/api`
- Uç noktaların listesi ve test arayüzü: `http://localhost:5268/swagger`
